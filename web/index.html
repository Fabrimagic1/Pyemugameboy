PyEmu Game Boy

Emulatore Game Boy nel browser, con audio. Versione JavaScript dell'emulatore Python del repository.

Scegli un file .gb oppure trascinalo qui.

Tastiera: frecce = croce direzionale, Z = A, X = B, Invio = Start, Backspace = Select.
La ROM resta solo nella memoria di questa scheda: non viene inviata a nessun server né salvata. Chiudendo o ricaricando la pagina, ROM e salvataggi vengono persi.
Per continuare in un secondo momento usa Salva stato: scarica un file .gbstate con il punto esatto del gioco (compreso il salvataggio interno). La volta dopo carica la stessa ROM e poi Carica stato (o trascina il file qui).
